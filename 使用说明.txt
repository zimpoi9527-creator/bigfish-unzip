================================================================
 Complex-Unzip-Tool MOD  ——  改造版使用说明
================================================================

【改了什么】
原版两个痛点：
  1. 分卷修复逻辑只对“解压出来的东西”生效，你直接拖进去的那个改名文件
     永远不会被修复；
  2. 分卷分组只认“文件名等于基名”，part1.jpg 和 vol.zip.002 分不到一组；
     文件夹拖拽时更是把每一卷当成独立压缩包，必然失败。

改造后：
  · 完全按文件内容（魔数）识别格式，扩展名是什么都不影响；
  · 分卷无论哪一卷被改成什么后缀，都能自动聚合成一组再解压；
  · 分卷解压用「影子目录 + NTFS 硬链接」完成：
      在同目录建一个临时子目录，把各卷硬链接成 archive.001/002/…
      交给 7-Zip 正常解压，全程不复制数据、不重命名、不修改你的原文件；
  · 文件夹拖拽改为先扫描分卷集合、再逐组处理，分卷只解一次；
  · 多个文件一起拖进来时，同一分卷集合只会处理一次；
  · 策略是“先按普通压缩包解，失败才尝试分卷拼合”，所以正常压缩包
    绝不会被误判；
  · 加密分卷同样支持（密码本 / 手动输入都行）。

【怎么用】
方式一（推荐）：把要解压的文件或文件夹，直接拖到
        complex-unzip-tool-mod.exe  上
方式二：如果没有 exe（或想直接跑源码），拖到
        拖到这里解压.bat  上（需要本机有 Python 3.10+）

启动后会问密码：
  直接回车 → 再按 1  = 按无密码解压
  直接回车 → 再按 2  = 从密码库选择密码本（编号从 0 开始，
                        [0] 0_temp.txt 是临时密码本）

密码库在 passwords\ 目录：
  0_temp.txt  临时密码，自己往里贴，一行一个
  1_all.txt   主密码库，成功用过的密码会自动追加进来
  其他 .txt   自己新建即可，程序会自动识别

【输出在哪】
解出来的文件在“原文件旁边”的 <原文件名>_<6位随机码> 目录里。
原始压缩包不会被删除、不会被改名。

【已知限制】
  · 所有分卷都被改成没有数字的乱名时，靠“体积 + 修改时间 + 名字顺序”
    推断卷序；如果目录里同时存在无关的同尺寸文件，可能推断失败
    （此时程序会报错跳过，不会损坏任何文件）；
  · 分卷集合必须完整（第一卷 + 后续所有卷在同一目录）；
  · 依然只支持 7-Zip 能识别的格式；
  · 由 WinZip 生成的分卷（首卷 .z01、末卷 .zip）理论支持但未实测。

【测试情况】

B 分卷第一卷改名（同基名）   PASS
C 分卷第一卷改名（不同基名） PASS
D 全员乱名分卷      PASS
E 文件夹拖拽        PASS
F 压缩包内嵌套伪装分卷 PASS
G 加密分卷          PASS
H 7z 格式分卷       PASS
I 中文 + 空格路径   PASS
J 同尺寸正常包不误判 PASS

以上均校验输出文件 md5 与原文一致，且原始分卷文件 md5 未变。
